AIRLINE RESERVATION SYSTEM - TEST ACCOUNTS
==========================================

These sample accounts are created the first time the program runs (when
there is no airline-data.ser file yet). Use them to test each role.


WHERE TO LOG IN
---------------
Passengers log in with "1 - Login".
Admin and Staff log in with "4 - Staff Portal".
An account used on the wrong screen is refused.


ACCOUNTS
--------
Role        Log in through     Username       Password
Admin       Staff Portal       admin          admin123
Staff       Staff Portal       staff01        staff123
Passenger   Login              passenger01    passenger123

New passenger accounts can be made with "2 - Create Account".
New Staff accounts can only be made by an Admin (Manage Users).
